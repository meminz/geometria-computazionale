Installazione

Requisiti

  • Python 3.11
  • MediaPipe Face Landmarker model (in working directory)
    • wget https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task

Da PyPI

uv venv --python 3.11
uv pip install facemarks

API Principali

import_mesh_and_setup

import_mesh_and_setup(mesh_path: str) -> dict

Carica una mesh 3D e la prepara per l'elaborazione. Restituisce un dizionario contenente la mesh in formati multipli.

Parametro Tipo Descrizione
mesh_path str Percorso del file mesh (OBJ, PLY, ecc.)

Restituisce: dict con chiavi:

  • "original" — Oggetto mesh Open3D standard (per visualizzazione)
  • "textured" — Mesh texturizzata per il rendering
  • "tensor" — Mesh tensore per accelerazione del raycasting

predict

predict(meshes: dict, projections: int = 10) -> dict

Esegue l'intera pipeline di rilevamento 3D dei punti facciali su una mesh preparata.

Parametro Tipo Descrizione
meshes dict Output di import_mesh_and_setup()
projections int Numero di punti di vista per il rendering (predefinito: 10)

Restituisce: dict con chiavi:

  • "facemarks_3d" — Lista di 478 coordinate [x, y, z] dei punti facciali
  • "closest_vertex_ids" — Lista degli indici dei vertici mesh più vicini

render_result

render_result(mesh, landmarks_3d: list) -> None

Visualizza la mesh con i punti facciali rilevati usando il visualizzatore Open3D.

Parametro Tipo Descrizione
mesh o3d.geometry.TriangleMesh L'oggetto mesh originale
landmarks_3d list Coordinate dei punti facciali dalla predizione

save_facemarks_json

save_facemarks_json(prediction: dict, path: str) -> None

Esporta i risultati della predizione in un file JSON.

Parametro Tipo Descrizione
prediction dict Output di predict()
path str Percorso del file di output

Esempio Completo


import sys
from facemarks import (
    import_mesh_and_setup,
    predict,
    save_facemarks_json,
    render_result
)

# Caricamento e preparazione della mesh 3D
meshes = import_mesh_and_setup(sys.argv[1])

# Predizione dei punti facciali 3D
prediction = predict(meshes, projections=20)

# Estrazione dei risultati
facemarks_3d = prediction["facemarks_3d"]
closest_vertex_ids = prediction["closest_vertex_ids"]

# Visualizzazione dei risultati
render_result(meshes["original"], facemarks_3d)

# Salvataggio in JSON (opzionale)
# save_facemarks_json(prediction, "landmarks.json")

Interni del Modulo

facemarks.predict

La funzione predict() orchestra l'intera pipeline:

  1. Inizializzazione del rilevatore MediaPipe FaceMesh
  2. Creazione del renderer Open3D offscreen
  3. Generazione degli angoli di vista (griglia sistematica attorno all'orientamento frontale)
  4. Per ogni punto di vista: rendering della mesh, rilevamento 2D, calcolo raggi prospettici, trasformazione nello spazio mondo
  5. Aggregazione dei raggi e esecuzione di raycasting() per trovare le posizioni 3D

facemarks.raycast

Il modulo raycast contiene la logica di intersezione raggio-mesh e le strategie di aggregazione (vedi Teoria per i dettagli):

  • raycasting() — Punto di ingresso principale; elabora i raggi per punto e restituisce posizioni 3D
  • closest_point_method() — Punto ai minimi quadrati più vicino a tutti i raggi
  • closest_point_hit_method() — Centroide dei punti hit validi
  • tangent_plane_method() — Adattamento piano locale per affinamento
  • plane_raycast() — Intersezione vettorizzata raggio-piano

facemarks._geometry_processing

Utility interne di geometria:

  • _hpr_mesh_based() — Hidden Point Removal per stima della visibilità
  • _perspective_rays_directions() — Calcolo direzioni dei raggi da intrinseche camera
  • _hit_coords() — Estrazione coordinate 3D dai risultati raycast

Altri Moduli

  • facemarks._mp_utils — Inizializzazione rilevatore MediaPipe e conversione immagini
  • facemarks._triangles — Topologia di triangolazione FaceMesh (478 punti)
  • facemarks.io_utils — Caricamento mesh e I/O JSON
  • facemarks.rendering — Visualizzazione dei risultati

Formato di Input

FaceMarks accetta mesh triangolari nei formati supportati da Open3D:

  • OBJ — Wavefront OBJ (con o senza materiali MTL)
  • PLY — Stanford PLY
  • OFF — Object File Format
  • STL — Stereolithography

La mesh deve rappresentare una geometria facciale. La topologia dei punti segue la convenzione MediaPipe FaceMesh (478 punti).

Formato di Output

L'esportazione JSON (save_facemarks_json()) produce un file con questa struttura: 

{
    "facemarks_3d": [
        [x0, y0, z0],
        [x1, y1, z1],
        ...
    ],
    "closest_vertex_ids": [v0, v1, ...]
}

Le coordinate sono nel sistema di coordinate originale della mesh (nessuna normalizzazione).

Risoluzione Problemi

Nessun hit per il punto X

I raggi per questo punto non hanno intersecato la mesh da alcun punto di vista. Cause comuni:

  • Il punto è in una regione occlusa (es. dentro la bocca, dietro il naso)
  • La mesh ha buchi o geometria incompleta
  • La configurazione dei punti di vista non copre questa regione

Nessun raggio per il punto X

Il rilevatore 2D non ha individuato questo punto in alcuna vista. Questo può accadere per punti sul bordo del volto o in regioni a basso contrasto.

Errore nel rilevamento del volto

Il rilevatore MediaPipe non ha trovato un volto in un numero sufficiente di viste renderizzate. Assicurarsi che la mesh sia centrata e orientata frontalmente.

Performance

Le prestazioni del raycasting dipendono dalla complessità della mesh. Per mesh grandi (>100k triangoli), considerare la semplificazione della mesh.
